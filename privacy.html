Назначение и владелец

MONO — личная лаборатория исследования рыночных данных. Владелец и контакт по вопросам доступа и удаления данных: salimovsf@gmail.com.

Доступ к данным Google

После разрешения пользователя приложение получает токены OAuth для Google Drive API. Используется область доступа drive.file, позволяющая работать с файлами, созданными приложением или предоставленными ему. Это разрешение может включать просмотр, создание, изменение и удаление таких файлов; текущий архиватор выполняет копирование и проверку, без автоматического удаления облачных файлов.

MONO обрабатывает содержимое файлов проекта, их названия, идентификаторы, размер, контрольные суммы и сведения о папках. Приложение может запрашивать сведения об общем и свободном месте на Диске. Пароль аккаунта Google приложение не получает. Подключение не запрашивает доступ к Gmail, контактам или календарю.

Как используются данные

Данные используются только для сохранения рыночного архива, организации папок, восстановления файлов, проверки целостности и отображения состояния загрузки владельцу. Данные Google не используются для рекламы, продажи третьим лицам или обучения общих моделей искусственного интеллекта.

Хранение и защита

Архивные копии хранятся на Google Диске владельца. Исходные рыночные данные, журнал загрузок и контрольные суммы хранятся на сервере проекта. Токены доступа и конфигурация подключения хранятся в файлах с ограниченными правами на сервере и на компьютере владельца, используемом для настройки. Передача в Google выполняется по HTTPS. Секреты не включаются в публичные страницы и отчёты.

Передача и доступ

Google обрабатывает архив и запросы API для предоставления своего сервиса. Серверный провайдер предоставляет инфраструктуру хранения и вычислений. MONO не продаёт пользовательские данные и не предоставляет их рекламным компаниям. Доступ к файлам на Google Диске определяется настройками общего доступа самого владельца; предоставленная по ссылке папка может быть доступна обладателям этой ссылки.

Эти публичные информационные страницы размещаются на GitHub Pages. На них нет добавленных MONO аналитических скриптов, рекламных трекеров или формы входа. Хостинг может обрабатывать технические сведения посетителей, в том числе IP-адреса, согласно политике GitHub.

Сроки хранения и удаление

Облачные копии сохраняются до удаления владельцем. Для отдельных исходных файлов на сервере действуют правила хранения проекта; текущий сборщик живых данных использует семидневное хранение. Токены сохраняются на время подключения и настройки, включая защищённые резервные конфигурации. Владелец может удалить файлы непосредственно на Диске либо запросить удаление серверных копий, журналов и сохранённых конфигураций по контактному адресу выше.

Как отключить доступ

Разрешение можно отозвать в разделе подключений аккаунта Google, выбрав MONO. После отзыва приложение утратит возможность выполнять новые авторизованные операции. Отзыв разрешения сам по себе не удаляет ранее сохранённые файлы или локальные конфигурации.

Ограниченное использование

Использование MONO информации, полученной через Google API, и передача такой информации другим приложениям осуществляются в соответствии с Google API Services User Data Policy, включая требования Limited Use.
